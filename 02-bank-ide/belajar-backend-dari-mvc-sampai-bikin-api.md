# Belajar Backend dari Bingung MVC sampai Bisa Bikin API

## Konsep awal
Melanjutkan materi MVC dengan jalur belajar backend untuk pemula, tetapi tidak menjanjikan seluruh backend selesai dalam satu video.

## Masalah ide awal
- Frasa `dari konsep dasar hingga siap bikin API` terlalu luas untuk satu video.
- Sudutnya masih generik dan bisa dibuat oleh banyak channel programming.
- Pengalaman spesifik creator saat pertama memahami MVC dan membuat API belum tercatat.

## Arah yang lebih kuat
Gunakan satu proyek API yang memang pernah dibuat creator untuk menunjukkan alur:

`request masuk → route → controller → proses data → response`

Fokus pada perubahan pemahaman creator dari bingung melihat struktur backend sampai mengerti aliran satu request. Database, autentikasi, validasi, dan deployment hanya dimasukkan jika benar-benar pernah diterapkan pada proyek tersebut dan masih muat.

## Bahan yang perlu digali
- Framework yang dipakai saat pertama memahami alur backend.
- API nyata yang pernah dibuat dan aman ditampilkan.
- Bagian yang paling membingungkan atau pernah salah.
- Hasil akhir yang benar-benar berhasil dibuat.

## Format sementara
Talking head dan screen recording kode yang sudah ada. Hindari membuat proyek baru khusus untuk video jika membutuhkan produksi lebih dari satu hari.

## Status filter
- Lolos modal nol, editing simpel, on-camera, dan potensi produksi mingguan.
