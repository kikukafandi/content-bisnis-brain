# Lembar Rekam — Spek Laptop untuk Mulai Coding

## Hook (kata-per-kata)

“Kalau cuma mau mulai coding, kalian nggak perlu laptop gaming. Core i3 dan RAM 8 GB sebenarnya sudah bisa—asal jangan salah pilih bagian lainnya.”

## Segmen 1 — Jawaban singkat

### Spek minimum yang masih masuk akal

- Intel Core i3 atau AMD Ryzen 3 generasi modern.
- RAM 8 GB.
- SSD 256 GB.
- Layar Full HD.
- GPU terintegrasi sudah cukup.

### Spek yang lebih nyaman dan tahan beberapa tahun

- Intel Core i5 atau AMD Ryzen 5 generasi modern.
- RAM 16 GB.
- SSD NVMe 512 GB.
- Layar Full HD IPS.
- GPU terintegrasi tetap cukup untuk coding umum.

- Jangan menilai prosesor hanya dari nama i3, i5, Ryzen 3, atau Ryzen 5; lihat juga generasi dan kelas prosesornya.

## Segmen 2 — Prosesor

- Untuk HTML, CSS, JavaScript, Python dasar, Git, dan tugas kuliah: Core i3/Ryzen 3 modern atau setara sudah cukup sebagai titik awal.
- Untuk Flutter, Docker, kompilasi lebih berat, dan banyak aplikasi terbuka: Core i5/Ryzen 5 modern lebih nyaman.
- Tidak wajib mengejar Core i7/Ryzen 7 jika hanya belajar coding umum.
- Lebih baik prosesor kelas menengah yang relatif baru daripada hanya tergoda nama kelas tinggi dari generasi lama.

## Segmen 3 — RAM

- 8 GB: cukup untuk mulai coding dasar dengan beban yang dijaga.
- 16 GB: rekomendasi paling aman untuk mahasiswa IT karena lebih lega untuk browser, editor, emulator, dan Docker.
- Di atas 16 GB: baru menarik jika memakai banyak container, VM, dataset besar, atau tool berat secara bersamaan.
- Cek apakah RAM dapat di-upgrade.
- Pengalaman creator: saat masih 8 GB, sengaja tidak melakukan pekerjaan berat karena sadar kapasitasnya terbatas.
- RAM kemudian di-upgrade sendiri menjadi 20 GB karena laptop memang bisa di-upgrade.

## Segmen 4 — Penyimpanan

- Wajib SSD; hindari menjadikan HDD sebagai penyimpanan sistem utama.
- 256 GB: cukup untuk mulai, tetapi ruangnya cepat sempit setelah sistem operasi, aplikasi, SDK, dan proyek masuk.
- 512 GB: pilihan lebih nyaman untuk pemakaian kuliah dan coding beberapa tahun.
- NVMe lebih cepat, tetapi prioritas pertama tetap menggunakan SSD dan kapasitas yang cukup.
- Cek apakah tersedia slot tambahan atau SSD dapat diganti.

## Segmen 5 — GPU

- Coding web, aplikasi dasar, Laravel, Next.js, dan belajar bahasa pemrograman tidak membutuhkan GPU dedicated.
- GPU terintegrasi sudah cukup untuk kebutuhan tersebut.
- GPU dedicated dipertimbangkan jika benar-benar akan menjalankan AI/ML lokal, 3D, atau game development.
- Pengalaman creator: saat tugas deep learning dijalankan lokal, laptop blank dan freeze.
- Jangan menyimpulkan komponen tertentu sebagai penyebab karena penyebabnya belum terverifikasi.

## Segmen 6 — Layar dan hal kecil yang kepakai setiap hari

- Minimal Full HD agar teks dan area editor lebih nyaman.
- Panel IPS lebih nyaman dilihat dari berbagai sudut.
- Perhatikan keyboard, baterai, bobot, dan port karena laptop akan sering dibawa ke kampus.
- Pastikan port sesuai kebutuhan tanpa harus langsung membeli adaptor tambahan.
- Spek kencang tetapi berat, boros baterai, atau keyboard tidak nyaman tetap bisa mengganggu pemakaian harian.

## Segmen 7 — Bukti dari laptop yang dipakai

- Lenovo IdeaPad 3 14ITL6 hanya sebagai contoh, bukan rekomendasi merek.
- Intel Core i5-1135G7, 4 core dan 8 thread.
- RAM 20 GB, hasil upgrade dari 8 GB.
- SSD 512 GB + 256 GB.
- Ubuntu 24.04.
- Pernah dipakai untuk ADB, VS Code, Flutter, Docker, Next.js, dan Laravel tanpa terasa berat.
- Batas yang pernah ditemui adalah training deep learning lokal.

## Segmen 8 — Rekomendasi akhir berdasarkan kebutuhan

### Hanya mulai belajar coding

- Core i3/Ryzen 3 modern.
- RAM 8 GB, lebih bagus jika bisa di-upgrade.
- SSD 256 GB.
- GPU terintegrasi.

### Kuliah IT dan ingin lebih nyaman

- Core i5/Ryzen 5 modern.
- RAM 16 GB.
- SSD NVMe 512 GB.
- GPU terintegrasi.

### AI/ML lokal, 3D, game, atau VM berat

- Kebutuhannya berbeda dari “coding doang”.
- Cek kebutuhan software dan proyek secara spesifik.
- Pertimbangkan prosesor, RAM lebih besar, GPU dedicated, pendinginan, dan kapasitas SSD sesuai beban nyata.

## Penutup

- Untuk coding umum, prioritaskan prosesor modern, RAM minimal 8 GB, dan SSD.
- Kalau anggaran memungkinkan, Core i5/Ryzen 5, RAM 16 GB, dan SSD 512 GB adalah titik nyaman.
- Jangan membayar GPU dedicated kalau kebutuhannya hanya coding web dan tugas kuliah dasar.
