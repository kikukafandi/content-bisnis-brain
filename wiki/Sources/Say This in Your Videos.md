## Enam Storylocks (Teknik Kata-Kunci Retensi)

### 1. Term Branding — *Labeling Effect*
- Beri nama pada konsep/framework, bukan cuma jelaskan
- Nama = mental trademark → penonton *perlu* tahu artinya
- Contoh: *Storylocks*, *Value Equation*, *Thousand True Fans*
- **Takti**: Paketkan ide kontrarian/best framework → beri nama khas

### 2. Embedded Truths — *If vs When*
- Ganti *if/maybe/might/could/probably* → *when/the reason/once you/this is how*
- *If* = memberi pilihan ragu; *When* = menutup pintu keluar perhatian
- Contoh: *Some creators might be making a mistake* → *The mistake most creators make is this*
- **Takti**: Hapus semua kata *hedging*; tulis seolah sudah benar

### 3. Thought Narration — *Mind Reading Effect*
- Ucapkan apa yang penonton pikirkan: *"Now the question you're probably thinking is..."*
- Dua manfaat: (1) trust instan (2) penonton butuh jawaban → personal connection
- **Takti**: Setelah poin besar, tanya *"What should the viewer be thinking right now?"* → tulis di skrip

### 4. Negative Frames — *Loss Aversion*
- Otak 2× lebih termotivasi hindari pain dari pada dapet reward
- Balik positif jadi negatif: *Use this hook* → *Stop making hooks like this*
- Format: *Don't / Never / Worst / Mistake / Killing / Costing you*
- **Takti**: *Negative flip* — ambil saran bagus, balik jadi peringatan

### 5. Loop Openers — *Re-hook Every 20–30s (Shorts)*
- Perhatian = jam pasir; loop opener = balik jam pasir
- Frasa: *Here's the thing though / But that's not even the most interesting part / Most people stop here, but actually...*
- **Kunci**: pakai *contrast word* di tengah (*but, actually, instead, turns out, except, yet*)
- **Takti**: Setiap section besar → tambah loop opener pindah ke section berikutnya

### 6. Contrast Words — *Bedrock Storytelling*
- *But, actually, instead, turns out, except, yet* = bridge gap ekspektasi vs realita
- *But* = kata kontras paling kuat
- Contrast = engine yang menggerakkan 5 storylock lain
- **Takti**: Setiap kalimat poin utama → pecah jadi 2, masukkan *but/actually/instead*

## Hubungan Storylocks (Diagram Mental)

```
Contrast Words (But/Actually/Instead) → Engine utama
    │
    ├─ Term Branding → nama kontras dengan ekspektasi biasa
    ├─ Embedded Truths → keyakinan kontras dengan keraguan
    ├─ Thought Narration → pemikiran penonton kontras dengan ekspektasi
    ├─ Negative Frames → peringatan kontras dengan nasihat biasa
    └─ Loop Openers → transisi kontras (A but B)
```

## Relevansi untuk Talking Head Creator Kikuk

| Storylock | Aplikasi Praktis Kikuk |
|-----------|------------------------|
| **Term Branding** | *Definisi Data Trap*, *LCP/INP/CLS Trinity*, *Hukum Ohm Gap* |
| **Embedded Truths** | *"When you define data this way..."* bukan *"If you define data..."* |
| **Thought Narration** | *"Now you might be thinking: resistor mah cuma baca warna doang..."* |
| **Negative Frames** | *"Stop mengompres semua gambar sebelum cek elemen LCP"* |
| **Loop Openers** | *"LCP fixed. Tapi INP ini justru lebih jahat..."* |
| **Contrast Words** | Setiap kalimat poin → pecah & sisip *but/actually/instead* |

## Checklist Skrip Pra-Rekam (5 Menit)
- [ ] Hapus semua *if, maybe, might, could, probably*
- [ ] Beri nama pada 2–3 framework/konsep kunci
- [ ] Sisipkan 2–3 *thought narration* di transisi poin besar
- [ ] Balik 1–2 saran jadi *negative frame*
- [ ] Tambah *loop opener* tiap 20–30 detik (Shorts) / 60–90 detik (Long-form)
- [ ] Pecah 5 kalimat poin utama → masukkan *but/actually/instead/turns out*
