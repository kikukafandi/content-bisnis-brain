Tempat JSON-LD

Masukkan strukturnya ke dalam tag script.

Gunakan tipe application/ld+json. Tag ini biasanya diletakkan di bagian head halaman.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "TechArticle",
  "headline": "Judul tutorial",
  "author": {
    "@type": "Person",
    "name": "Kikuk"
  }
}
</script>

Checklist akhir10

Intinya: buat schema yang sesuai dengan isi halaman.

Tidak perlu memasang semua jenis schema hanya karena tersedia.

  • Pilih tipe schema yang sesuai.
  • Ambil data dari sumber yang sama dengan halaman.
  • Gunakan URL lengkap dan tanggal ISO 8601.
  • Jelaskan hubungan penulis dan penerbit.
  • Pastikan output JSON-LD aman.
  • Tes HTML yang benar-benar dikirim ke browser.
