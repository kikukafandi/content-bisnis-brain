# Kebutuhan Spesifikasi Laptop untuk Mulai Coding

Spesifikasi laptop sebaiknya ditentukan dari beban kerja, bukan merek. Coding web dasar, tugas kuliah, dan belajar bahasa pemrograman tidak membutuhkan GPU dedicated. Beban seperti emulator Android, banyak layanan lokal, mesin virtual, AI atau machine learning, dan game development membutuhkan sumber daya lebih besar.

## Patokan kebutuhan

| Komponen | Cukup untuk mulai | Lebih nyaman | Kapan perlu lebih tinggi |
|---|---|---|---|
| Prosesor | Core i3/Ryzen 3 modern atau setara | Core i5/Ryzen 5 modern atau setara | Kompilasi berat, VM, emulator, dan multitasking intensif |
| RAM | 8 GB, idealnya bisa di-upgrade | 16 GB | Banyak VM, dataset besar, atau proyek berat |
| Penyimpanan | SSD 256 GB | SSD NVMe 512 GB | Banyak SDK, VM, dataset, atau proyek besar |
| Layar | Full HD | Full HD IPS | Utamakan kenyamanan baca kode, bukan sekadar ukuran |
| GPU | Terintegrasi | Terintegrasi | Dedicated jika kebutuhan AI/ML lokal, 3D, atau game memang nyata |

## Hal yang sering terlewat

- RAM yang dapat ditingkatkan bisa lebih berguna daripada mengejar kelas prosesor tanpa melihat kebutuhan.
- SSD lebih penting untuk respons sistem dibanding kapasitas HDD besar.
- Bobot, baterai, keyboard, layar, dan port memengaruhi pemakaian harian di kampus.
- Nama seri prosesor saja tidak cukup; generasi, kelas daya, dan konfigurasi laptop ikut memengaruhi performa.
- Patokan ini adalah titik awal dari sumber, bukan jaminan untuk setiap software atau kurikulum.
