# Bahan Mentah Belajar Backend dari MVC sampai API

## Pengalaman tervalidasi
- Pertama belajar dan memakai pola MVC melalui CodeIgniter dan Laravel.
- Backend yang paling sering dibuat menggunakan Laravel.
- Pernah memakai NestJS untuk seleksi magang.
- Pertama kali membuat API menggunakan stack JavaScript dan React dengan MySQL sebagai database; susunannya mirip MERN, tetapi MongoDB diganti MySQL.
- Pernah membuat beberapa API untuk proyek lomba yang tersimpan di repository GitHub.
- Produk belum diluncurkan sehingga detail proyek belum tentu bisa ditampilkan.
- Bagian yang paling membingungkan adalah menerjemahkan requirement client atau proyek menjadi definisi data yang tepat.

## Contoh konkret tervalidasi
- Saat membuat data artikel, requirement awal belum memuat status publikasi.
- Belakangan artikel ternyata membutuhkan field boolean `is_published` untuk membedakan artikel yang masih disiapkan dan yang sudah boleh tampil.
- Perubahan tersebut berdampak ke migration, model, validasi request, endpoint, dan query artikel.

## Batas klaim
- Jangan menyebut produk sudah diluncurkan.
- Repository, nama proyek, kode asli, dan data proyek tidak boleh ditampilkan.
- Gunakan contoh artikel baru yang sederhana saat menjelaskan konsep.
